# E-commerce Sales Data Analysis

A professional, portfolio-ready data analysis project that explores e-commerce sales performance, profitability, customer segments, shipping behavior, and product-level opportunities. The project combines Python-based exploratory data analysis, RFM customer segmentation, SQLite queries, saved visual outputs, and business recommendations in a clean notebook workflow.

## Objectives

- Clean and prepare raw e-commerce order data for reliable analysis.
- Measure key business KPIs including revenue, profit, margin, average order value, and shipping speed.
- Identify sales trends across months, categories, regions, products, and customer segments.
- Analyze profitability risks caused by discounts, low-margin sub-categories, and loss-making products.
- Segment customers using RFM analysis to support retention and targeting decisions.
- Provide standalone SQL queries that reproduce core business summaries.

## Dataset Description

The source CSV should be placed in `data/raw/ecommerce_sales.csv`. It contains order-level e-commerce transaction data with the following columns:

| Column | Meaning |
| --- | --- |
| `Order ID` | Unique identifier for each order. |
| `Product Name` | Name of the product purchased. |
| `Category` | High-level product category. |
| `Sub-Category` | More detailed product grouping within each category. |
| `Sales` | Revenue generated by the order line. |
| `Quantity` | Number of units purchased. |
| `Discount` | Discount applied to the transaction. |
| `Profit` | Profit generated by the order line. |
| `Shipping Cost` | Cost associated with shipping the order. |
| `Customer Name` | Customer who placed the order. |
| `Customer Segment` | Customer segment classification. |
| `Region` | Sales region. |
| `State` | State where the order was placed or delivered. |
| `Order Date` | Date the order was placed. |
| `Ship Date` | Date the order was shipped. |

## How to Run the Project

1. Clone or download this repository.
2. Place the raw CSV file at `data/raw/ecommerce_sales.csv`.
3. Create and activate a virtual environment:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```
4. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
5. Start Jupyter from the project root:
   ```bash
   jupyter notebook
   ```
6. Open `notebooks/sales_analysis.ipynb` and run the cells from top to bottom.
7. Review generated outputs:
   - Cleaned CSV: `data/cleaned/cleaned_orders.csv`
   - Chart PNGs: `outputs/charts/`
   - SQL result CSVs: `outputs/reports/`

## Key Findings

- The notebook calculates the strongest revenue products, categories, regions, and customer segments from the provided dataset.
- Profit margin analysis highlights sub-categories and products that may be dragging down profitability.
- Discount analysis helps evaluate whether discounting is meaningfully associated with lower profit margins.
- RFM segmentation identifies Champions, Loyal Customers, At-Risk customers, and Regular customers for targeted actions.
